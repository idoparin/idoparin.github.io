Reading FITS files

FITS (Flexible Image Transport System) files are used to store images and tables recorded in observations (usually 2D)

Each FITS files consists of several HDUs (Header Data Unit) that is on some extent close to the concept of a dictionary in python

HDU consists of a header and data field. Headers comprise multiple 'cards' that contain information about the data: keyword, value and a comment

params = hdul[0].header

dx, dy = params['CDELT1'], params['CDELT2']

X, Y = np.mgrid[xc - 0.5*N*dx:xc + 0.5*N*dx:complex(0, N),
           yc - 0.5*N*dy:yc + 0.5*N*dy:complex(0, N)]

'''
Create a sample gaussian brightness distribution

def gauss2d(x=0, y=0, mx=0, my=0, sx=10, sy=10):
    return 1. / (2. * np.pi * sx * sy) * np.exp(-((x - mx)**2. /
     (2. * sx**2.) + (y - my)**2. / (2. * sy**2.)))

x = np.linspace(xc - 0.5*N*dx, xc + 0.5*N*dx, N)
y = np.linspace(yc - 0.5*N*dy, yc + 0.5*N*dy, N)
x, y = np.meshgrid(x, y)
imag = gauss2d(x, y, mx=xc*np.ones_like(x), my=yc*np.ones_like(x))
